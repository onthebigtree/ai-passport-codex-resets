# AI Passport · Codex Resets

适配 ESP32-C3、240×320 竖屏和三个实体按键的独立应用，启动后直接进入新的界面。网页预览使用真实公开数据，复现相同布局；它是浏览器重绘，不是固件模拟器。

## 页面与操作

| 页面 | 显示内容 | 上 / 下 | OK |
| --- | --- | --- | --- |
| 重置追踪 | 距最近一次已执行重置的时间、累计次数、平均间隔、上次重置时间 | 切换追踪和挑战 | 查看最新公告 |
| 最新公告 | 常规 / 备用重置、英文原文、是否另有计划重置 | 滚动 | 返回 |
| 28 天挑战 | 美西时间、挑战日、7×4 日历、当日结果 | 切页 | 进入日历选择 |
| 日历选择 | 未开始、等待、改进、重置、两者都有、核实中、当日结束 | 前后选日，首尾循环 | 返回 |

长按 **OK** 刷新，最多每 15 秒一次。长按 **上键** 打开或关闭网络设置。双击不执行操作。网页还支持方向键、Enter、Escape、Shift+上键（配网预览）和 Shift+Enter（刷新）。

重置追踪使用北京时间 UTC+8；挑战遵循 `America/Los_Angeles`，处理美西夏令时。计划重置不算已执行重置。已结束但未确认结果的日期保持中性状态，不推断承诺是否失败。不预测下一次重置，也不展示个人账号额度。

## 首次启动与配网

1. 首次启动打开临时 WPA2 热点，在屏幕上查看设备专属名称和随机密码。
2. 手机连接该热点，手动打开 `http://192.168.4.1`。没有实现自动弹出的门户页。
3. 输入 2.4 GHz Wi-Fi。设备获取 IP 后才保存配置；失败时保留原有配置。连接结果显示在设备屏幕。
4. 成功后关闭热点和设置服务，校准时间，然后直接通过 HTTPS 读取数据。不依赖电脑、预览服务、账号或 API Key。

设置入口 10 分钟后关闭，可长按上键重开。每次重新开启生成新热点密码。Wi-Fi 凭据仅保存在设备 NVS，不写入日志或固件构建产物。基线未开启 NVS 加密和安全启动。配网、TLS、无线连接和断电保存仍需真机验收。

## 数据、刷新与边界

数据来自 [Codex Resets](https://codex-resets.com/zh-CN)，与 OpenAI 无关联。[公开 API 文档](https://codex-resets.com/api/docs)。

| 页面 | 来源 | 处理规则 |
| --- | --- | --- |
| 追踪 | `GET https://codex-resets.com/api/v1/status` | 最多 12 KiB JSON，校验结构，保留最新公告最多 511 字节 ASCII 原文 |
| 挑战 | `GET https://codex-resets.com/zh-CN/tibo-28` | 流式读取 HTML，单标签最多 768 字节，完整响应最多 256 KiB；必须识别出 28 个状态和有效开始日期 |

每 5 分钟刷新，各部分分别记录成功同步时间。请求失败或结构无效时不覆盖有效数据；固件把带版本的快照保存在 NVS，显示离线或错误状态。首次成功前显示未知。挑战暂无文档化公开 API，网站 HTML 变化可能导致适配失败，此时明确提示更新失败。所有请求只读，不投票、不订阅、不发送通知。

原生挑战页展示每天的结果摘要，完整公告在原站查看。中文固定文案使用生成的 14 px 字体；公开重置 API 返回英文原文。动态公告中的非 ASCII 字符明确替换为 `?`，没有打包全量动态中文或 Emoji 字库。网站统计和设备电量独立，网页预览电量显示未知。

## 网页预览

在仓库根目录运行：

```sh
python3 preview/server.py --port 8765
```

打开 `http://127.0.0.1:8765`。Python 标准库服务只代理两个公开读取接口，解决浏览器跨域限制，缓存 5 分钟，仅监听本机回环地址。不代理凭据和任意网址。“模拟离线”开关保留上次数据。固件不依赖此预览服务。

## 构建与验证

激活仓库要求的 ESP-IDF **5.5.3**，运行完整门禁：

```sh
./tools/validate.sh
```

校验后的合并固件位于 `build/FoloToy-AI-Passport-full.bin`；按内容哈希归档的目录保留匹配的 ELF、MAP 和清单。取得明确许可后，在 **0x0** 烧录合并固件。合并烧录可能重置 NVS，包括配网和缓存。不需要整片擦除。

模型测试覆盖 HTML 分块、未知结构、不完整响应、时区边界、按键导航和文本边界；JSON 测试使用 ESP-IDF 的实际 cJSON；预览测试覆盖局部失败和旧缓存保留。固件门禁还会用 24 KiB 内存池运行实际 LVGL 界面，检查真实字形描述并连续切页 100 次。日历直接绘制，不创建 56 个子控件。主机渲染不复现板载内存、SPI 时序或物理圆角遮罩。原仓库检查全部保留。门禁在 macOS 选择适用的链接器参数，actionlint 下载用 Python 校验 SHA-256。如果 Xcode 与 Command Line Tools SDK 不匹配，在本次命令通过 `SDKROOT` 选择兼容的已安装 SDK，不修改全局开发环境。

文案变化后再重新生成字体：

```sh
npm ci --ignore-scripts
python3 -m venv .toolchain/font-env
.toolchain/font-env/bin/pip install fonttools brotli
.toolchain/font-env/bin/python tools/generate_reset_font.py
python3 tools/check_reset_font.py
```
